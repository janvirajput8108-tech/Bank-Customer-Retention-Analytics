# 🏦 Bank Customer Intelligence & Customer Retention Analytics

## 📌 Overview
This project was completed during my **NOVITECH Data Analytics Internship**. It analyzes bank customer behavior, predicts customer churn using Machine Learning, and provides interactive business insights through Power BI.

## 🚀 Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Power BI
- DAX
- Excel

## 🤖 Machine Learning
- K-Means Clustering
- Random Forest Classifier
- Model Accuracy: 86.4%

## 📊 Dashboard Features
- KPI Cards
- Customer Churn Analysis
- Geography Analysis
- Gender Analysis
- Age Group Analysis
- Customer Segmentation
- Interactive Slicers

## 📈 Business Insights
- Churn Rate: 20.37%
- Total Customers: 10,000
- Exited Customers: 2,037
- Average Balance: 76.49K
